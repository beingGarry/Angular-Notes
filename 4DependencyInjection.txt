Dependency Injection

Dependency injection is the concept of creating service objects at runtime automatically and loading these service object into the constructor of the component as per the necessity of the components.

Angular uses dependency injection to manage how diff pieces of an application interact with each other.

Create Component
import

@Component({

})

export class {

 constructor(private dataservice : DataService) {}

 ngOnInit(): void {
   use this dataservice
 }
}

How dependency Injection work here:

Service Registration :

The dataservice is decorated with @Injectable({ providedIn : 'root' })

This means angular will create a single instance of this service and provide it throughout the application (frontend)

Injecting the service :

In component → constructor → we declare private property dataservice of Dataservice. Angular automatically injects an instance of Dataservice into this property

Using the service :

ngOnInit → call method → to fetch the data and then assign it to the component data.
