1. What is HTML?

HTML (HyperText Markup Language) is used to create the structure of web pages.

Example:

<h1>Hello</h1>
<p>This is paragraph</p>
h1 → heading
p → paragraph

Angular templates are also HTML files with extra Angular syntax.

2. Semantic HTML (Very Important)

- Semantic tags describe the meaning of content.

Example:

<header></header>
<nav></nav>
<section></section>
<article></article>
<footer></footer>

- Why Important?

Better SEO
Better accessibility
Better readability
Screen readers understand structure

Interview Question

Q: Difference between div and semantic tags?

Answer:
div has no meaning. Semantic tags describe the purpose of content.

Example:

<div>Menu</div>
<nav>Menu</nav>

nav is better because browser and screen readers understand it is navigation.

3. Block vs Inline Elements
- Block Elements Take full width.
- Block elements start from new line and take full width.

Examples:div, p, h1, section

- Inline Elements Take only required width.
- Inline elements stay in same line and take only required content width

Examples: span, a, strong

Interview Question
Q: Difference between block and inline elements?

Answer:
Block elements start from new line and take full width.
Inline elements stay in same line and take only required content width.

4. ID vs Class
- ID : Unique element => <div id="header"></div>

- Class : Reusable =>  <div class="card"></div>
Interview Question
Q: Difference between id and class?

Answer:

id should be unique
class can be reused on multiple elements

4. Event Bubbling

Event flows from child to parent.

Example:

<div onclick="parent()">
  <button onclick="child()">Click</button>
</div>

Clicking button triggers:

child()
parent()
Why?

Because event bubbles upward.

Stop Bubbling
event.stopPropagation()

Interview Question
Q: What is event bubbling?

Answer:
Event starts from target element and propagates upward to parent elements.

5. Event Capturing

Opposite of bubbling.

Flow:

Parent → Child

- Bubbling => Child → Parent

Interview Question
Q: Difference between bubbling and capturing?
Bubbling	                  Capturing
Child → Parent	            Parent → Child
Default behavior	          Optional
6. Local Storage

Same as localStorage but cleared when tab closes.

Example:

Difference
localStorage	                   sessionStorage
Permanent	                        Temporary
